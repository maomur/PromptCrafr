# **App Name**: PromptCraft

## Core Features:

- Prompt Creation: Allow users to create new prompts with title, description, and content fields.
- Prompt Listing: Display a list of prompts with key information, such as title and a short snippet of the content.
- Prompt Editing: Enable users to edit existing prompts.
- Prompt Deletion: Allow users to delete prompts they no longer need.

## Style Guidelines:

- Primary color: Blue (#007AFF) to reflect the iOS/macOS system color, giving the app a native Apple feel.
- Background color: Light gray (#F0F0F0) for a clean, modern look that's easy on the eyes.
- Accent color: Green (#34C759) for success states (e.g., saving prompts) and important actions.
- Body and headline font: 'Inter', a sans-serif font, will be used for a modern and readable aesthetic.
- Use simple, line-based icons in the style of Apple's SF Symbols to maintain visual consistency with iOS/macOS.
- Employ a clean, card-based layout, with each prompt represented by a card in a list. Use clear and consistent spacing.
- Incorporate subtle animations and transitions, like fades and slides, for a smooth and responsive user experience.
